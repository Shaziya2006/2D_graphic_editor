# 2D Graphics Editor

A menu-driven 2D Graphics Editor implemented in C using a 2D character array as the canvas.

## Features

- Draw Rectangle
- Draw Line
- Draw Circle
- Draw Triangle
- Add Objects
- Delete Objects
- Modify Objects
- Display Canvas

## Technologies Used

- C Programming
- Git & GitHub
- VS Code
