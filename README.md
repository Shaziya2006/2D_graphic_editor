# 2D_graphic_editor
# 2D Graphics Editor

A menu-driven 2D Graphics Editor implemented in C using a 2D character array as the canvas.

## Features

- Draw Rectangle
- Draw Line
- Draw Circle
- Draw Triangle
- Add Objects
- Delete Objects
- Modify Objects
- Display Canvas
## Project Structure

graphics.h  - Common declarations
canvas.c    - Canvas management
draw.c      - Drawing algorithms
objects.c   - Object management
menu.c      - Menu system
main.c      - Program entry point
Makefile    - Build automation
